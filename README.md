# 急診物語 ER Quest

> 急診住院醫師養成像素 RPG：在時間壓力下問診、理學檢查、下 Order、做處置，救回病人。
> **醫學教育用途，非臨床決策依據。所有案例皆為虛構，不含任何病人資料。**

GBA 時代風格的原創像素 RPG。所有美術、角色與音樂都是原創，由程式即時生成，不使用任何商業遊戲素材。

## 怎麼玩

| 操作 | 鍵盤 | 手機 |
|---|---|---|
| 移動 / 選擇 | 方向鍵 或 WASD | 十字鍵 |
| 確認 / 對話（A） | Z、Enter、空白鍵 | A |
| 取消（B） | X、Esc | B |
| 選單（START） | Shift、M | START |

- 每天早上先找**總醫師晨會**，再到診間幫病人看診。
- 「對戰」就是看診：**問診 / 理學檢查 / 檢查 / 報告**。每個動作都會花時間，要問得有重點。
- 看完找總醫師**交班**，再去**值班室**休息進入下一天。

## 遊戲進程（v0.4：Clerk 篇＋PGY 篇）

| 職級 | 狀態 | 指令 | 場景 |
|---|---|---|---|
| **Clerk** | ✅ 可遊玩 | 問診、理學檢查、初步檢驗、報告（主診斷＋DDx） | 一般診區 |
| **PGY** | ✅ 可遊玩 | ＋CT／POCUS、處置（會改變生命徵象）、Disposition | 急診留觀區 |
| R1–R3 | 規劃中 | ＋POCUS、CT、侵入性處置、CPR | 急救室、CPR 室／Trauma Blue |
| 主治醫師 | 規劃中 | ＋團隊指揮、大量傷患 | 導管室／手術房 |

- **班表**：每天晨會分配 2 位病人，看完用 I-PASS 交班，下班看日報。
- **推理值**：問無關問題 −3、做無關 PE −5、開不必要檢驗 −5；漏問關鍵題 −8、漏問 Red flag −15、漏做關鍵 PE −10、漏開必要檢驗 −8；主診斷錯誤直接進 M&M 回顧。
- **評量**：結算對應 Mini-CEX 五面向（1–9 分），關鍵特徵需 ≥ 80% 才算通過。
- **升等考**：Lv 10 且 10 案中 8 案 B 以上 → 主治辦公室 Boss 戰 → 進化成 PGY。
- **課堂模式**：直接選任一病例，不影響存檔，適合投影討論。

## PGY 篇（v0.4）

- **場景**：一般診區右側紅門 → 急診留觀區（6 床），晨會找急診總醫師。
- **處置**：給氧、輸液、抗生素、胰島素、tPA 等 30 項；病人穩定度隨時間下降，必要處置有時限，給錯（例如主動脈剝離給 tPA、DKA 未知血鉀先給胰島素）會扣分並惡化。
- **Disposition**：出院、留觀、住院、加護病房或緊急會診，選錯扣分並說明理由。
- **10 案**：Urosepsis 敗血性休克、DKA、上消化道出血、COPD 急性惡化、高血鉀、急性缺血性中風、長者低血糖、過敏性休克、急性心衰竭、蜂窩性組織炎合併敗血症。
- **升等考**：Lv 20 且 8 案 B 以上 → 急救室「以中風表現的 A 型主動脈剝離」→ 進化為 R1。

## Procedure 小遊戲（v0.5）

在走廊走路時，護理師會隨機跑來請你做 procedure（晨會後才會出現，每天最多 3 次，可以拒絕）。每個 procedure 都是約 1 分鐘的小遊戲，最後一題安全重點題。評價 S／A／B／C／F，白袍幣與 EXP 依評價給（S 40 幣＋30 EXP … F 0 幣＋2 EXP），每次消耗 5 精神值。紀錄在 START →「技能護照」。

| Procedure | 小遊戲 |
|---|---|
| 放置鼻胃管 | 選 NEX 置入長度；病人吞嚥時按 A 推進，時機錯會嗆咳 |
| 導尿 Foley | 無菌步驟排序；按住 ← → 讓導管維持在中線 |
| ABG | 移動指尖找脈搏最強點；搏動進入綠區時進針 |
| 傷口濕敷換藥 | 由內往外擦，往回擦扣分，按 A 換新紗布 |
| 上石膏夾板 | 節奏疊 8 層；維持手腕功能位到硬化 |
| 傷口縫合 | 5 針，在等距的入針、出針點按 A |
| 轉送病人 | 出發前準備清單；推床閃避障礙並處理 SpO₂ 下降 |

## 家屬代述

- 每位病人約 30% 機率改由家屬（女兒、太太、同事…）代述；課堂模式可直接指定。
- 家屬會說「不確定」或與事實有出入，需用「查證」（藥袋／雲端藥歷、過去病歷、救護紀錄、再問病人）確認，未查證的關鍵資訊不算數。
- 開場與說明病情各有一次溝通選擇（自我介紹、同理、不給不實保證），結果反映在 Mini-CEX。

## 白袍幣與福利社（v0.3）

- **白袍幣**：看診評價 S 50／A 30／B 20／C 5；第一次通過 +30、零扣分 +20；已拿 S 的案例重複練習減半；交班滿分 +20；當天兩位都 A 以上全勤獎 +30。
- **福利社**（候診區）：40 件裝備（聽診器、刷手服、頭部、胸前配件、鞋子）與 14 隻醫學主題原創寵物，可先預覽再購買；咖啡 30 幣恢復 30 精神值。
- **置物櫃**（值班室）：換裝備、帶寵物；裝備即時反映在地圖、看診背影與進化動畫，寵物會跟在身後。
- **傳說級**：只能靠成就解鎖，不能購買。額外功能只提升體驗（例如 ECG 動畫、教科書說明、學習摘要），**不影響評分、提示或升等考資格，也不會透露科別**。
- **設定**：START → 設定，可調文字速度（慢／中／快／瞬間）與走路速度。
- **存檔**：v0.2 的存檔會自動升級到 v0.3，進度完整保留。

## Clerk 篇案例

心臟（AF、心衰竭惡化）、胸腔（社區型肺炎、氣喘）、消化（潰瘍出血、胰臟炎）、腎臟（腎盂腎炎、腎前性 AKI）、外科（闌尾炎、膽囊炎），以及升等考（以上腹痛表現的 Inferior STEMI）。案例腳本已由臨床教師審定。

## 教學設計框架

| 維度 | 框架 | 在遊戲中的落點 |
|---|---|---|
| 定義元素 | ACGME EM Milestones / EPA | 徽章、等級門檻 |
| 解釋因果 | Dual-process theory、Cognitive Load Theory | 時間壓力、精神值 |
| 設計教學 | Deliberate practice＋即時回饋、Self-Determination Theory | 重玩、M&M 回顧、自主選路線 |

## 新增案例

Clerk 案例是獨立的 JSON 檔（`data/cases/clerk/*.json`），不需要改程式碼：`history` 每題為 `[選單短標, 問題, 病人回答, K/RF/R/X]`，`pe`／`labs` 只列關鍵與相關項目，其餘自動視為正常。新增後在 `src/engine/clerkMenus.js` 的 `CLERK_CASES` 登錄，並更新 `sw.js` 快取清單。
